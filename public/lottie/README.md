# Lottie 动画素材

把从 [lottiefiles.com](https://lottiefiles.com/) 下载的素材放进本目录,
按时刻名命名(`.lottie` 或 `.json` 都可以,`.lottie` 优先),放进来即生效,
不用改任何代码;缺失的时刻自动退回 CSS 动效。

| 文件名 | 触发时刻 | 建议搜索词 |
| --- | --- | --- |
| `boss-clear.lottie` | 课程通关 | trophy winner / confetti burst |
| `level-up.lottie` | 升级 | level up / sparkle success |
| `quest-done.lottie` | 每日任务完成 / 复习完成 | check success celebration |
| `chest-open.lottie` | 开宝箱 | treasure chest open |
| `streak.lottie` | 连胜里程碑 | fire flame streak |
| `term-unlock.lottie` | 卷宗词条解锁 | book magic sparkle |

挑选建议:透明背景、时长 1.5–3 秒、单次播放型(非循环)、
文件 ≤ 200KB(会随页面加载)。

# 学者公会 · 浏览器插件

在 bilibili / YouTube **原站**看公开课（登录态、原生清晰度、弹幕都在），
播放到 80% 自动把进度同步回你自己搭的 Guild 站点，计入副本进度与 XP。

## 为什么需要插件

站内 iframe 内嵌播放器受第三方 Cookie 限制，拿不到你的登录态，
清晰度上限低且无法读取播放进度。插件在原站页面里运行，这两个问题都不存在。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`，右上角开启「开发者模式」
2. 点「加载已解压的扩展程序」，选择本目录（`extension/`）
3. 在 Guild 站点 **设置 → 浏览器插件 token** 生成一个 token
4. 点插件图标 → 插件设置，填站点地址（如 `http://localhost:3000`）与 token，保存并测试连接

## 用法

- 在 B 站/YouTube 打开课程视频，正常观看；播放到 80% 右下角会浮出提示，进度已同步
- 点插件图标可看到当前视频对应的课程与集数，也能手动点「标记这一集为已看」
- 不在课程库里的视频会显示提示，不会产生任何请求以外的副作用

## 隐私

- 插件只读取当前播放页的视频 id、分 P 号与播放进度比例，不读取账号信息、不修改页面内容
- token 存在浏览器 `storage.sync` 中，只发送给你自己配置的站点地址
- 站点侧只存 token 的 SHA-256；明文丢失后无法找回，重新生成即可，旧的记得撤销

## 匹配规则

后端用 `content/` 里的课程数据建反查索引：

- **合集类课程**（每集独立稿件，如 GAMES104、TheCherno）：按稿件 BV 号直接命中具体集
- **多分 P 课程**（如 CS61A、CSAPP）：按稿件 BV 号 + `?p=N` 定位集数
- YouTube 按视频 id 或播放列表 id 匹配
